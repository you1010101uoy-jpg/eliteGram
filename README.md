# ELITIUM — GitHub project

Это исходный проект ранней версии мессенджера ELITIUM на React + Vite + Supabase.

## Что уже есть в проекте
- Адаптивный интерфейс для телефона и компьютера.
- Чёрная и светлая темы с сохранением выбора.
- Экран входа по номеру телефона через Supabase Auth SMS OTP.
- Создание профиля с уникальным username (`@ID`).
- Базовые таблицы профилей, диалогов, участников, сообщений и каналов.
- Отправка текста и Realtime-подписка на новые сообщения для подключённого диалога.
- Поисковое поле по локальному списку чатов.

## Важно: это не готовый публичный мессенджер
Для реальной работы нужно создать и настроить проект Supabase, включить SMS-провайдера, применить SQL, задать переменные окружения и провести тестирование безопасности. Создание каналов, подписки, публикации, группы, отправка файлов, голосовые, звонки, push-уведомления и поиск пользователей ещё требуют реализации. В интерфейсе некоторые элементы пока показывают подсказку вместо работающей функции.

## 1. GitHub — загрузка с телефона
1. Распакуйте архив на телефоне.
2. Откройте GitHub и создайте репозиторий `ELITIUM`.
3. В репозитории нажмите **Add file → Upload files**.
4. Загрузите содержимое распакованной папки (включая `src` и `supabase`), а не сам ZIP.
5. Нажмите **Commit changes**.

Если мобильный браузер не позволяет выбрать сразу папки, загрузите файлы по частям или включите в браузере «Версия для ПК».

## 2. Supabase
1. Создайте проект на https://supabase.com/.
2. Откройте SQL Editor → New query.
3. Скопируйте весь файл `supabase/schema.sql`, вставьте и нажмите Run.
4. В Authentication → Providers настройте Phone/SMS и подключите SMS-провайдера. Доступность и стоимость зависят от провайдера и региона.
5. В Project Settings → API скопируйте Project URL и anon/public key.

## 3. Переменные окружения
Создайте локально файл `.env.local` по образцу `.env.example`:
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

Не публикуйте service_role key, пароли базы, SMS-токены или другие секреты в GitHub. Для Vercel эти две публичные клиентские переменные добавляются в Project Settings → Environment Variables.

## 4. Локальный запуск (если есть компьютер)
```bash
npm install
npm run dev
```
Для проверки сборки:
```bash
npm run build
```

## 5. Публикация через Vercel
1. Откройте https://vercel.com/ и войдите через GitHub.
2. Import Project → выберите `ELITIUM`.
3. Framework preset: Vite.
4. Добавьте переменные окружения из `.env.local`.
5. Нажмите Deploy.

## Примечания по безопасности и приватности
- Номер телефона не выводится в публичный профиль; поиск по номеру в этой версии не реализован.
- Для реального сервиса перед запуском нужны аудит RLS-политик, проверка регистрации, ограничение частоты запросов, правила хранения файлов и политика конфиденциальности.
- Не используйте реальные личные данные до завершения тестирования.
